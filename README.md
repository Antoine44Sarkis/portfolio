📄 Overview
Antoine Sarkis’s personal web‑based portfolio, built with plain HTML, CSS, and JavaScript, 
showcasing small interactive projects and games. It demonstrates front‑end skills—DOM manipulation, 
event handling, canvas animation—and provides a simple “profile” section to introduce the author.
